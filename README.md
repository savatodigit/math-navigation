# Учебный сайт «Математические основы судовождения»

Статический одностраничный сайт для публикации на GitHub Pages.

## Состав проекта
- `index.html` — структура страницы;
- `styles.css` — оформление;
- `materials.js` — список файлов, отображаемых в разделе «Учебные материалы»;
- `materials/` — папка для учебных файлов.

## Как добавить учебный материал
1. Скопируйте файл в папку `materials/`.
2. Откройте `materials.js`.
3. Добавьте объект в массив `materials`, например:

```js
{
  title: "Лекция 1. Введение",
  category: "Лекции",
  description: "PDF · 2,4 МБ",
  file: "materials/lecture-01.pdf"
}
```

4. Сохраните изменения и загрузите обновлённые файлы в репозиторий GitHub.

Поддерживаются PDF, DOCX, XLSX, PPTX, ZIP и другие типы файлов. Браузер скачает файл по ссылке; поведение для некоторых типов файлов может зависеть от браузера.

## Публикация через GitHub Pages
1. Войдите в GitHub и создайте новый **Public repository**, например `math-navigation`.
2. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `materials.js`, `README.md` и папку `materials`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После публикации GitHub покажет адрес сайта вида `https://ВАШ-ЛОГИН.github.io/math-navigation/`.

## Важно
GitHub Pages публикует содержимое репозитория в интернете. Не размещайте там персональные данные студентов, ведомости с оценками или материалы, которые нельзя распространять публично. Для крупных файлов действуют ограничения GitHub; лучше держать отдельные файлы небольшими.
